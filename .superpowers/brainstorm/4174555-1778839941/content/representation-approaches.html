Agent-friendly representation over splats / point clouds

Three viable architecture shapes for a general indoor/outdoor robot swarm.

A. Scene Graph First
3D map
↓
Objects · Places · Relations
↓
LLM queries graph

Scene graph first

Convert geometry into entities and relations early. Great for inspect/understand and semantic search; weaker outdoors unless region/terrain primitives are carefully designed.

B. Query Services First
3D map + robot state
↓
Tools: free_space(), frontiers(), objects(), hazards()
↓
Agent calls tools

Query services first

Expose APIs over geometry without committing to one grand world model. Fastest to prototype; can become messy if schemas are not disciplined.

C. Layered Belief Graph + Query Services
Local 3D maps
↓
Metric · Region · Semantic · Belief · Commitment layers
↓
LLM tools + planners + swarm allocator

Layered belief graph + tools

Recommended. Keeps dense geometry grounded locally, exposes semantic/topological/belief abstractions, and supports search, navigation, inspection, and manipulation.
