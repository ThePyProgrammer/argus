Core data model: everything is a claim with evidence

The graph stores entities and relations, but every useful fact carries belief/provenance metadata.

Graph primitives
Entity
robot · region · frontier · object · hazard · person · path · terrain patch
↕ relations
Relation
contains · connects · blocks · near · observed_by · assigned_to · reachable_by
↕ backed by
Evidence
point cloud slice · splat IDs · image frame · detector output · robot report
Belief metadata on every claim
confidence: 0.74
source_robot: rover_3
observed_at: timestamp
frame_id: map / robot / local_submap
valid_until / stale_after
conflicts: [claim_17]

Example

hazard_12 blocks path_segment_4 is not stored as absolute truth. It is stored as a claim: observed by robot_3, at time T, confidence 0.74, backed by a local point-cloud/splat region, stale after 5 minutes, conflicting with robot_5's older clear-path report.
