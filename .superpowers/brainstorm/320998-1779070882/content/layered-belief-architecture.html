Recommended architecture: Layered Belief Graph + Query Services

Dense 3D data stays grounded below; agents interact through tools over a belief-aware graph.

Data flow
Robot-local 3D substrate
point clouds · Gaussian splats · poses · sensor frames
↓ extract/query
Metric layer
occupancy · ESDF · terrain · traversability · collision geometry
↓ segment/abstract
Region + topology layer
frontiers · zones · paths · rooms · corridors · outdoor terrain patches
↓ classify/ground
Semantic + affordance layer
objects · hazards · landmarks · humans · manipulable things · affordances
↓ fuse across robots
Belief + provenance layer
confidence · source robot · timestamp · conflicts · stale state
↓ coordinate
Commitment layer
task assignments · reservations · intentions · resource locks
↓ tools
Agent-facing query API
find · summarize · plan · check · allocate · explain

Core idea

The graph is not only objects and rooms. It stores anything the swarm can act on: regions, paths, frontiers, hazards, terrain patches, robot capabilities, uncertainty, observations, and commitments.
