## Tech Debt and Deferred Concerns

- **Phase 2 / LOC-CTRL-04:** `src/bridge/multi_bridge.py` still runs platform-local controllers from `Go2Platform.make_controller()` and writes controls directly. The env and single bridge use `ControllerRegistry`/`controller_dispatch`; multi bridge should either be unified with that seam or explicitly documented as a platform-runtime boundary.
- **Phase 2/5 placeholder metadata:** WBC placeholder capability metadata advertises `torque_or_joint_position`, which is not one of the v4.0 env action modes. Because WBC is unavailable, this is not a runtime blocker, but future metadata/docs should clarify the action contract.
- **Validation metadata:** Phases 1, 2, 3, and 6 have stale `VALIDATION.md` Wave 0/Nyquist rows despite later `VERIFICATION.md` reports passing. Clean this if strict governance hygiene matters before the next milestone.
