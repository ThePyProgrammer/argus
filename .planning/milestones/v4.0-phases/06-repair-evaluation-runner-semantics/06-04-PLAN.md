<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted/broken env_factory -> evaluation runner | Custom env implementations may ignore Gymnasium termination/truncation and can otherwise cause unbounded runner loops. |
| CLI/test matrix -> env construction and loop control | `max_episode_steps` crosses from user/config input through validation into runner execution and must bound resource usage. |
| output_root -> local artifact filesystem | Generated artifacts must remain under the resolved output root. |
| CSV artifacts -> spreadsheet consumers | String cells in CSV may be interpreted as formulas by external spreadsheet tools. |
| developer AI guidance -> package runtime/tests | AI-SPEC allows Claude Agent SDK only for developer assistance; runtime and tests must remain deterministic and offline. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-16 | Denial of Service | `run_evaluation_matrix` loop in `src/locomotion/evaluation.py` | mitigate | Maintain a runner-owned `runner_step_count` and force `truncated = True` when it reaches validated `cell["max_episode_steps"]`, independent of env `terminated`/`truncated`. |
| T-06-17 | Repudiation | evaluation artifacts after forced cap | mitigate | Preserve final capped step row, episode row, manifest row, and summary/comparison artifacts so the bounded run leaves auditable output. |
| T-06-18 | Tampering | `_prepare_run_dir()` artifact path containment | mitigate | Do not alter resolved-root containment logic; acceptance greps for `Run directory escapes output root`. |
| T-06-19 | Tampering / Information Disclosure | `episodes.csv` writer | mitigate | Preserve `writer.writerow({field: _csv_safe(row.get(field, "")) for field in _EPISODE_CSV_FIELDS})` so CSV formula safety remains active. |
| T-06-20 | Supply Chain / Information Disclosure | runtime AI dependency creep | mitigate | Do not add `anthropic`, `claude_agent_sdk`, `ClaudeSDKClient`, SDK `query()`, network calls, or LLM judges to `src`, tests, or dependencies; verify with grep. |
| T-06-21 | Denial of Service | regression test for non-terminating env | mitigate | Use a fail-fast fake env that raises after `max_episode_steps + 1` step calls, not sleeps/timeouts/threads, so the red test fails without hanging. |
</threat_model>
