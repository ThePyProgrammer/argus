<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Gymnasium action -> env step -> MuJoCo control | User/controller action values become physics controls and metric inputs. |
| MuJoCo state -> collector -> Gymnasium info | Simulation state becomes downstream benchmark telemetry. |
| metrics config -> termination semantics | Threshold config can terminate episodes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | `ArgusGo2Env.step` metric inputs | mitigate | Record only validated 12-joint targets and copied finite MuJoCo state after action validation and physics stepping. |
| T-03-02 | Repudiation / Integrity | `info["locomotion_metrics"]` action quality labels | mitigate | Surface proxy field names from collector unchanged; tests assert no physical-energy top-level labels. |
| T-03-03 | Denial of Service | per-step info | mitigate | Put compact family payload under `info["locomotion_metrics"]`; terminal summaries only on terminated/truncated steps. |
| T-03-04 | Integrity | foot mapping in env reset | mitigate | Resolve strict `Go2FootMapping` after real MuJoCo model initialization; mapping failures fail reset rather than silently disabling contact metrics. |
| T-03-05 | Information Disclosure / DoS | oversized info payload | mitigate | Do not expose raw `qpos`, `qvel`, `data.contact`, or unbounded histories in `info`; expose family scalar/list summaries only. |
</threat_model>
