```python
ACTION_MODE_VELOCITY = "velocity_command"

```

`build_action_space("velocity_command")` returns shape `(3,)`, low `[-1.0, -1.0, -3.0]`, high `[1.0, 1.0, 3.0]`.

`build_action_space("joint_position")` returns shape `(12,)` with repeating Go2 joint bounds:
- hip: `[-1.0472, 1.0472]`
- thigh: `[-1.5708, 4.5379]`
- calf/knee: `[-2.7227, -0.83776]`

`build_action_space("residual_baseline")` returns shape `(12,)`, low `-0.25`, high `0.25` for every element.

`decode_action(action, mode, gait, dt, previous_command)` returns a finite `np.float64` shape `(12,)` control vector or raises `ValueError` before a caller writes `data.ctrl`.
