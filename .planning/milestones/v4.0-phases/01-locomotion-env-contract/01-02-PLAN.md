<interfaces>
Create and use these scenario contracts:

```python
@dataclass(frozen=True)
class ScenarioSpec:
    scenario_id: str
    display_name: str
    terrain_kind: str
    randomizes_terrain: bool = False
    has_disturbance: bool = False

@dataclass(frozen=True)
class ScenarioSample:
    scenario_id: str
    spawn_pose: tuple[float, float, float, float]
    terrain_parameters: dict[str, float | int | str]
    command_schedule: tuple[dict[str, float], ...]
    disturbance_schedule: tuple[dict[str, float], ...]
```

Required catalog keys: `flat_ground`, `low_friction`, `slope`, `rough_heightfield`, `push_disturbance`.

Deterministic defaults:
- `flat_ground`: friction coefficient `1.0`, slope radians `0.0`, heightfield size `0`, no disturbances.
- `low_friction`: friction coefficient `0.35`, slope radians `0.0`, heightfield size `0`, no disturbances.
- `slope`: friction coefficient `1.0`, slope radians sampled in `[0.0872665, 0.174533]`, heightfield size `0`, no disturbances.
- `rough_heightfield`: friction coefficient `1.0`, heightfield size from config, roughness amplitude sampled in `[0.015, 0.05]`, no disturbances.
- `push_disturbance`: friction coefficient `1.0`, slope radians `0.0`, push time sampled in `[0.5, 2.0]`, push force x sampled in `[30.0, 80.0]`, push duration `0.1`.

Every reset info must expose `sampled_parameters`, `command_schedule`, and `disturbance_schedule` derived only from `self.np_random`.
