<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller to `ArgusGo2Env.step` | Untrusted action reaches env state mutation and eventual physics control. |
| action helper to env state | Validated decoded controls become `previous_action` and future MuJoCo controls. |
| env info to benchmark consumer | Reproducibility metadata supports benchmark claims and later exported metrics. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-13 | Tampering | `ArgusGo2Env.step` | mitigate | Call `decode_action` before incrementing step count or mutating command/previous_action. |
| T-01-14 | Repudiation | step `info` | mitigate | Include seed, scenario id, sampled params, action mode, command schedule, and disturbance schedule in every step info. |
| T-01-15 | Denial of Service | env action space | mitigate | Construct fixed mode-specific spaces through `build_action_space`; reject mismatched runtime arrays. |
| T-01-16 | Tampering | residual mode state | mitigate | Use clipped residual decode from `actions.py` and never write raw residuals directly as joint targets. |
</threat_model>
