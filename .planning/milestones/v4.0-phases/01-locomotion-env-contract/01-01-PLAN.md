```python
@dataclass
class ArgusGo2EnvConfig:
    scenario_id: str = "flat_ground"
    action_mode: str = "velocity_command"
    model_dir: str = "models/unitree_go2"
    sim_steps_per_frame: int = 10
    max_episode_steps: int = 500
    render_mode: str | None = None
    heightfield_size: int = 16
```

Observation contract for Phase 1:
```python
observation = {
    "qpos": np.ndarray,          # shape (19,), dtype float32 where unavailable values are zero-filled before model load
    "qvel": np.ndarray,          # shape (18,), dtype float32 where unavailable values are zero-filled before model load
    "command": np.ndarray,       # shape (3,), dtype float32 [vx, vy, omega]
    "previous_action": np.ndarray, # shape (12,), dtype float32
}
```

Reset returns `(observation, info)`. Step returns `(observation, reward, terminated, truncated, info)` where `reward` is `float`, both booleans are Python `bool`, and `info` includes at least `seed`, `scenario_id`, `action_mode`, `step_count`, and `sim_time`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller to ArgusGo2Env.step | Untrusted action arrays enter physics/control preparation. |
| caller to ArgusGo2EnvConfig | User-provided config selects scenario/action mode and bounds episode/resource sizes. |
| ArgusGo2Env to MuJoCo | Validated controls and reset state will later cross into MuJoCo data arrays. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | `ArgusGo2Env.step` | mitigate | Validate velocity actions have shape `(3,)` and all finite values before updating command or previous action. |
| T-01-02 | Tampering | `ArgusGo2EnvConfig.scenario_id` | mitigate | Keep default scenario as the named id `flat_ground`; later scenario plan must reject unknown names before any XML/model path is built. |
| T-01-03 | Repudiation | `reset` and `step` info | mitigate | Emit `seed`, `scenario_id`, `action_mode`, `sampled_parameters`, `command_schedule`, and `disturbance_schedule` in info from the first contract implementation. |
| T-01-04 | Denial of Service | `heightfield_size`, `max_episode_steps`, action shape | mitigate | Bound `heightfield_size <= 64`, require `max_episode_steps >= 1`, and use fixed action dimensions from `action_space`. |
</threat_model>
