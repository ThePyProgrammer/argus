<interfaces>
Create these concrete contracts in `src/locomotion/controllers.py`:

```python
@dataclass(frozen=True)
class LocomotionCommand:
    vx: float = 0.0
    vy: float = 0.0
    yaw_rate: float = 0.0
    metadata: dict[str, Any] | None = None

@dataclass(frozen=True)
class ControllerResult:
    action: np.ndarray
    metadata: dict[str, Any]

@runtime_checkable
class LocomotionController(Protocol):
    CAPABILITIES: dict[str, Any]
    PARAMETER_SCHEMA: dict[str, Any]
    def reset(self, seed: int | None = None) -> None: ...
    def compute(self, observation: dict[str, Any], command: LocomotionCommand, dt: float) -> ControllerResult: ...
    @classmethod
    def available(cls) -> tuple[bool, str | None]: ...
```

Required registry ids: `analytical_trot`, `residual_policy`, `direct_policy`, `mpc`, `wbc`.
Required default id: `analytical_trot`.
Required capability keys: `family`, `action_mode`, `deterministic`, `observation_expectation`, `command_limits`, `cpu_latency_hint_ms`, `sim_supported`, `hardware_supported`, `model_requirements`, `multi_robot_supported`, `reproducibility`.
Required metadata keys for analytical baseline: `controller_id`, `display_name`, `family`, `action_mode`, `deterministic`, `parameter_hash`, `parameter_summary`, `capabilities`, `available`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> ControllerRegistry.create | Untrusted controller id string chooses a runtime controller. |
| registry -> optional controller class path | Lazy import boundary for future dependency-heavy controllers. |
| controller -> action target | Controller-produced numeric target crosses into downstream control sinks. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-01 | Tampering / Repudiation | `ControllerRegistry.create` | mitigate | Unknown ids raise `ValueError` containing `Unknown locomotion controller` and `Available:`; no fallback to `analytical_trot`. |
| T-2-02 | Denial of Service / Tampering | Placeholder classes and `ControllerRegistry.create` | mitigate | `available()` returns `(False, reason)` and `create()` raises `UnavailableControllerError` before constructing residual/direct/MPC/WBC placeholders. |
| T-2-03 | Tampering | `validate_controller_target`, `ControllerResult.action` | mitigate | Convert target to `np.float64`, require exact shape `(12,)`, and reject non-finite values before downstream sinks. |
| T-2-05 | Repudiation | `controller_metadata` and `AnalyticalTrotController.compute` | mitigate | Emit `controller_id`, `display_name`, `family`, `action_mode`, `deterministic`, `parameter_hash`, `parameter_summary`, `capabilities`, and availability fields. |
</threat_model>
