<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Runner memory -> filesystem | Benchmark data becomes persistent local JSONL/CSV/JSON/Markdown artifacts. |
| Saved artifacts -> offline comparison | Existing CSV/manifest data regenerates summaries without rerunning simulation. |
| CSV artifact -> spreadsheet application | String cells may be interpreted by spreadsheet software when opened by a human. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | Validated matrix from Plan 01 | mitigate | Preserve Plan 01 validation before artifact writes; tests assert invalid inputs leave no run directory. |
| T-04-02 | Tampering | Run directory/file creation | mitigate | Resolve output root, create one new timestamped child directory, reject escaped paths, and write only fixed filenames. |
| T-04-03 | Repudiation | Manifest, summary, offline regeneration | mitigate | Manifest records git commit, invocation args, matrix, env/action config, timestamp, file list, and per-run metadata; offline regeneration reads saved artifacts only. |
| T-04-04 | Tampering | `episodes.csv` string cells | mitigate | Prefix string cells beginning with `=`, `+`, `-`, or `@` with a single quote before writing CSV. |
| T-04-05 | Denial of Service | Artifact generation for matrices | mitigate | Preserve Plan 01 max matrix size and aggregate from bounded episode rows. |
</threat_model>
