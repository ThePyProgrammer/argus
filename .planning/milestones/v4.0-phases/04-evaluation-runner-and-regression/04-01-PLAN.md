<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI/config input -> evaluation matrix | User-provided controller/scenario/seed/config values become benchmark execution cells. |
| Matrix -> simulation factory | Validated cells become `ArgusGo2EnvConfig` instances and reset/step calls. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | `validate_evaluation_matrix` | mitigate | Validate controller ids/availability, scenario ids, unique bounded integer seeds, action mode, and numeric env config before any run directory or env constructor call. |
| T-04-02 | Tampering | Output path handling | mitigate | Plan 01 avoids artifact writes; Plan 02 must resolve output roots under `outputs/locomotion-evals/` and create new timestamped directories only after validation. |
| T-04-03 | Repudiation | In-memory result provenance | mitigate | Plan 01 preserves run_id/controller/scenario/seed/action_mode per row; Plan 02 adds manifest metadata and file list. |
| T-04-04 | Tampering | CSV export | mitigate | Not in Plan 01 write path; Plan 02 must sanitize spreadsheet-dangerous string cells before CSV writing. |
| T-04-05 | Denial of Service | Matrix expansion | mitigate | Enforce `max_matrix_runs=1000` and reject oversized matrices before simulation. |
</threat_model>
