## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | `eval-locomotion` CLI args | mitigate | Repeated flags and JSON config feed Plan 01 `validate_evaluation_matrix`; CLI does not start envs directly. |
| T-04-02 | Tampering | `--output-root` and `--from-run-dir` | mitigate | CLI passes paths to Plan 02 path-resolving artifact APIs; no arbitrary artifact filenames are accepted. |
| T-04-03 | Repudiation | CLI invocation metadata | mitigate | Pass `sys.argv[1:]` into manifest/config so regenerated comparisons can report original invocation. |
| T-04-04 | Tampering | CSV opened from CLI-generated artifacts | mitigate | CLI uses Plan 02 exporter with formula-safe CSV cells. |
| T-04-05 | Denial of Service | CLI matrix flags/config | mitigate | Expose `--max-matrix-runs` default `1000` and enforce through validation before run directory/env construction. |
</threat_model>
