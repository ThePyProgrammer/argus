    **1. Create Sparkline.tsx:**

    Zero-dependency SVG sparkline component:

    ```typescript
    interface SparklineProps {
      data: number[];
      width?: number;       // default 120
      height?: number;      // default 30
      color?: string;       // default '#2ecc71'
      baselineValue?: number;
      baselineColor?: string; // default '#555'
    }
    ```

    Implementation:
    - If data.length < 2, return null
    - Compute min/max of data array, range = max - min (|| 1 to avoid div-by-zero)
    - Map each data point to SVG coordinate: x = i * (width / (data.length - 1)), y = height - ((v - min) / range) * height
    - Join as space-separated points string for `<polyline>`
    - If baselineValue provided and within [min, max], render a dashed `<line>` at the corresponding Y position
    - SVG: `<svg width={width} height={height} style={{ display: 'block' }}>`
    - Baseline line: `<line x1={0} y1={baseY} x2={width} y2={baseY} stroke={baselineColor} strokeWidth={1} strokeDasharray="3,2" />`
    - Current value polyline: `<polyline fill="none" stroke={color} strokeWidth={1.5} points={points} />`
    - Export as default
