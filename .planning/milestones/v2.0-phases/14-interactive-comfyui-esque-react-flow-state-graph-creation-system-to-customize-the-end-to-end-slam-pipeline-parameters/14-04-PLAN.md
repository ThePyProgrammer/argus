1. Create `frontend/src/components/pipeline/PresetSelector.tsx`:

   **State from store**: `activePreset`, `availablePresets`, `isDirty`, `loadPresetGraph`, `setAvailablePresets`.

   **Local state**: `showDropdown` boolean, `showSaveInput` boolean, `saveInputName` string, `showConfirm` boolean, `pendingPresetName` string.

   **On mount (useEffect)**: Fetch `GET /api/pipeline/presets`, call `setAvailablePresets(data.presets)`.

   **Load preset handler**:
   1. If `isDirty` and user hasn't confirmed: set `showConfirm=true`, `pendingPresetName=name`. Return.
   2. Fetch `GET /api/pipeline/presets/{name}`.
   3. Deserialize response JSON (nodes + edges) into React Flow format using `deserializeGraph()` from pipelineSerializer.
   4. Call `loadPresetGraph(nodes, edges, name)`.

   **Save preset handler**:
   1. Serialize current graph via `usePipelineStore.getState().serializeForApply()`.
   2. POST `/api/pipeline/presets` with `{name: saveInputName, nodes: config.nodes, edges: config.edges}`.
   3. Refresh presets list.

   **Render**:
   - Container: display inline-flex, alignItems center, gap 8px.
   - Label: "Preset:" in 11px/600/#aaa.
   - Dropdown button: background '#1e1e32', border '1px solid #2a2a4a', color '#e0e0e0', padding '4px 12px', borderRadius 4px, fontSize 13px. Shows `activePreset || 'Custom'`.
   - Dropdown menu (when open): position absolute, background '#1e1e32', border '1px solid #2a2a4a', borderRadius 4px, zIndex 100, minWidth 200px, maxHeight 300px, overflowY auto.
     - For each preset: padding 8px, cursor pointer, hover background '#242448'. If builtIn: italic + gray "Built-in" badge (10px/#888).
     - Separator line.
     - "Save Current..." option that opens save input.
   - Save input: text input + "Save" button, shown when showSaveInput is true.
   - Use `ConfirmModal` (import from '../ConfirmModal') when loading preset with dirty graph: message "You have unsaved changes. Load preset '{name}' and discard current graph?"

2. Create `frontend/src/components/pipeline/ApplyBar.tsx`:

   **State from store**: `isDirty`, `isValid`, `validationErrors`, `isApplying`, `serializeForApply`, `markApplied`, `setIsApplying`, `validate`.

   **Local state**: `showConfirm` boolean, `showErrors` boolean.

   **Apply handler**:
   1. Call `validate()` on store.
   2. Read `isValid` from store. If not valid: set `showErrors=true`, return.
   3. Set `showConfirm=true`.

   **Confirm apply**:
   1. `setIsApplying(true)`.
   2. `const config = serializeForApply()`.
   3. `POST /api/pipeline/apply` with `{nodes: config.nodes, edges: config.edges}`.
   4. On success: `markApplied()`, `setIsApplying(false)`.
   5. On error: show error via toast or inline message, `setIsApplying(false)`.

   **Render**:
   - Container: height 48px, background '#1a1a2e', borderTop '1px solid #2a2a4a', display flex, alignItems center, justifyContent space-between, padding '0 16px'.
   - Left side:
     - PresetSelector component (import from './PresetSelector')
     - Modified indicator: if `isDirty`, show orange dot (8px circle, #ff9800) + "Modified" text in 11px/#ff9800. Else nothing.
   - Right side:
     - Validation status:
       - If valid: "Pipeline valid" in 11px/#2ecc71
       - If errors: "{N} validation error(s)" in 11px/#d32f2f, clickable to expand error list
     - "Apply Pipeline" button: background '#4fc3f7', color '#0a0a14', fontWeight 600, fontSize 13px, padding '6px 20px', borderRadius 4px, border none, cursor pointer. Disabled (opacity 0.5, cursor not-allowed) when isApplying or !isDirty.
   - Error list (when showErrors and validationErrors.length > 0): absolute positioned above the bar, background '#1e1e32', border '1px solid #d32f2f', padding 8px, borderRadius 4px. Each error: 11px/#d32f2f, with nodeId reference.
   - ConfirmModal: message "Apply pipeline configuration? This will restart the simulation."
   - RestartOverlay: shown when `isApplying` (import from '../RestartOverlay').
