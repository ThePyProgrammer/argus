       merger_params: dict = field(default_factory=dict)

   **`NodeCatalog` class** with `get_catalog() -> list[dict]` that:
   - Adds static node definitions for: sensor_rgbd, sensor_imu, filter_voxel_downsample, filter_noise_removal, filter_coord_transform, splitter, combiner, param_scalar, viz_output. Each with: `type`, `label`, `category`, `inputs` (list of {id, label, dataType, required}), `outputs` (same), `parameterSchema` (or null), `defaultParams`.
   - Calls `SLAMRegistry.list_backends()` and for each available backend adds a catalog entry with type=`slam_{name}`, category='slam', inputs=[image_in, imu_in], outputs=[pose_out, cloud_out], parameterSchema from backend, registryName=name.
   - Calls `MergeRegistry.list_strategies()` and for each adds type=`merger_{name}`, category='merger', inputs=[cloud_in, pose_in], outputs=[merged_out], parameterSchema from strategy, registryName=name.

   **`PipelineBuilder` class** with `build(graph_json: dict) -> PipelineConfig`:
   1. Extract nodes list and edges list from graph_json
   2. **Validate DAG:** Kahn's algorithm topological sort. If cycle detected, raise `ValueError(f"Pipeline contains a cycle through nodes: {cycle_node_ids}")`
   3. **Find SLAM node:** First node where type starts with "slam_". Extract registry name (strip "slam_" prefix). Verify it exists in SLAMRegistry via list_backends(). If not found, raise `ValueError(f"Unknown SLAM backend: {name}")`.
   4. **Find merger node:** Same pattern with "merger_" prefix, MergeRegistry.
   5. **Resolve parameter overrides:** For each edge, if source node type == "param_scalar", get source node's params["value"]. Find target node. The target handle id maps to the param key. Override target node's params[key] with the scalar value.
   6. **Build filter chain:** Collect nodes with type starting with "filter_" in topological order. Each becomes `{type: node_type, params: node_params}`.
   7. Return `PipelineConfig(backend_name, slam_params, merger_name, merger_params, filter_chain)`.

1. Create `backend/web/pipeline_routes.py`:

   ```python
   """Pipeline configuration REST API routes.

   Provides pipeline graph apply, preset management, and node catalog
   endpoints via /api/pipeline/* prefix.
   """

   import json
   import logging
   from pathlib import Path
   from fastapi import APIRouter, HTTPException, Request
   from pydantic import BaseModel

   from src.coordination.pipeline_builder import PipelineBuilder, NodeCatalog

   logger = logging.getLogger(__name__)
   router = APIRouter(prefix="/api/pipeline", tags=["pipeline"])

   PRESET_DIR = Path(__file__).parent.parent.parent / "data" / "presets"
   BUILTIN_DIR = PRESET_DIR / "builtin"
   USER_DIR = PRESET_DIR / "user"
   ```

   **Request models:**
   ```python
   class PipelineApplyRequest(BaseModel):
       nodes: list[dict]
       edges: list[dict]

   class PresetSaveRequest(BaseModel):
       name: str
       nodes: list[dict]
       edges: list[dict]
   ```

   **Endpoints:**
   - `POST /apply` -- Build via PipelineBuilder, catch ValueError -> HTTPException(422, detail=str(e)). Store config on `request.app.state.pending_pipeline_config`. Trigger restart via `command_callback({"action": "restart"})`. Return `{"status": "restarting"}`.
   - `GET /node-catalog` -- Return `{"nodes": NodeCatalog.get_catalog()}`.
   - `GET /presets` -- Scan BUILTIN_DIR and USER_DIR for .json files. Return `{"presets": [{name, builtIn, nodeCount}]}`. builtIn=true for files in builtin dir.
   - `POST /presets` -- Create USER_DIR if not exists. Write JSON file at `USER_DIR / f"{req.name}.json"` containing `{"name": req.name, "nodes": req.nodes, "edges": req.edges}`. Return `{"status": "saved", "name": req.name}`.
   - `GET /presets/{name}` -- Search BUILTIN_DIR then USER_DIR for `{name}.json`. If not found: 404. Return file contents as JSON.
   - `DELETE /presets/{name}` -- Only delete from USER_DIR (builtin are read-only). 404 if not found, 403 if builtin.
