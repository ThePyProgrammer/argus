   - Call _log_fading_trail(f"/merged/{rid}/trajectory", data["trajectory"], ROBOT_COLORS[rid])

8. `_log_fading_trail(self, entity, poses, color_rgb, max_segments=MAX_TRAIL_SEGMENTS)`:
   - Extract positions: [p[:3, 3] for p in poses]
   - If len(positions) < 2: return
   - Take last max_segments positions
   - Build segments: strips = [[recent[i], recent[i+1]] for i in range(n)]
   - Build colors: alpha = int(255 * (i+1) / n) for each segment; color = [*color_rgb, alpha]
   - rr.log(entity, rr.LineStrips3D(strips, colors=colors))

9. `_log_robot_panel(self, rid, data)`:
   - rr.log(f"/{rid}/camera/rgb", rr.Image(data["frame"].rgb))
   - Tint local_voxels with ROBOT_COLORS[rid]
   - rr.log(f"/{rid}/local_cloud", rr.Points3D(data["local_voxels"], colors=tinted_colors))

10. `_log_coverage_heatmap(self, occupied_voxels, frontier_cells)`:
    - If occupied_voxels is empty, return
    - Project occupied to 2D: xy = occupied_voxels[:, :2]
    - Compute bounding box min/max, snap to HEATMAP_RESOLUTION grid
    - Create grid of centers within bounding box
    - For each grid cell: check if any occupied voxel projects into it
    - Explored cells (occupied): green [0, 200, 0, 180]
    - Frontier cells (in frontier_cells if provided): yellow [200, 200, 0, 180]
    - Unexplored cells (neither): red [200, 0, 0, 100]
    - rr.log("/merged/heatmap", rr.Points3D(positions=cell_centers_3d_at_z0, colors=cell_colors, radii=HEATMAP_RESOLUTION/2))
    - NOTE: For performance, only render cells within bounding box of explored area + small margin, not entire theoretical grid. Use batch numpy operations, not loops.

11. `_log_voronoi_plane(self, midpoint_2d, direction_2d)`:
    - Compute perpendicular: perp = np.array([-direction_2d[1], direction_2d[0]]); normalize
    - p0 = midpoint_2d + perp * VORONOI_PLANE_HALF_WIDTH
    - p1 = midpoint_2d - perp * VORONOI_PLANE_HALF_WIDTH
    - vertices = 4 corners (p0 at z=0, p1 at z=0, p1 at z=height, p0 at z=height)
    - color = [200, 200, 200, VORONOI_PLANE_ALPHA]
    - rr.log("/merged/voronoi_plane", rr.Mesh3D(vertex_positions=vertices, triangle_indices=[[0,1,2],[0,2,3]], vertex_colors=[color]*4))
