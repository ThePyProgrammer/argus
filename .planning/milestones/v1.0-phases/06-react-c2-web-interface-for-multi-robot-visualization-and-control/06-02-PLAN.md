Create `src/c2-frontend/src/hooks/useWebSocket.ts`:
- Custom hook `useWebSocket(url: string = 'ws://localhost:8000/ws')`
- On mount: creates WebSocket, sets binaryType = 'arraybuffer'
- On open: no special action (server sends robot_list automatically)
- On text message: JSON.parse, switch on msg.type:
  - `robot_list`: call `useRobotStore.getState().setRobotList(payload.robots)`
  - `pose_update`: call `useRobotStore.getState().updatePose(msg.robot_id, payload.position, payload.rotation)`
  - `cloud_delta`: call `useRobotStore.getState().appendCloudDelta(payload.positions, payload.colors)`
  - `cloud_full`: call `useRobotStore.getState().setCloudFull(payload.positions, payload.colors)`
  - `stats`: call `useRobotStore.getState().updateStats(payload)`
  - `trajectory`: call `useRobotStore.getState().updateTrajectory(msg.robot_id, payload.positions, payload.alphas)`
- On binary message: decode header -- byte 0 is type (0x01 = camera_frame), byte 1 is id_len, next id_len bytes are robot_id ASCII, rest is JPEG. Create Blob, URL.createObjectURL, call `useRobotStore.getState().setCameraUrl(robotId, url)`
- Expose `sendCommand` function: `(cmd) => ws.send(JSON.stringify({ type: 'command', payload: cmd }))`
- On mount, register sendCommand with controlStore: `useControlStore.getState().setSendCommand(sendCommand)`
- Reconnect on close after 2 second delay
- Cleanup on unmount: close WebSocket
