    **Create `src/exploration/exploration_loop.py`:**

    Implement `ExplorationLoop` class with the following structure:

    ```python
    class ExplorationLoop:
        def __init__(self, bridge: SimWorldGymBridge, slam: SLAMPipeline,
                     octomap: OctoMapBuilder, config: ExplorationConfig | None = None):
            self._bridge = bridge
            self._slam = slam
            self._octomap = octomap
            self._config = config or ExplorationConfig()
            self._frontier_detector = FrontierDetector(
                resolution=self._config.voxel_resolution,
                min_cluster_size=self._config.min_cluster_size)
            self._goal_selector = GoalSelector(strategy=self._config.goal_strategy)
            self._path_planner = PathPlanner()
            self._coverage_tracker = CoverageTracker(voxel_resolution=self._config.voxel_resolution)

        def run(self) -> ExplorationResult:
            """Run the full exploration loop. Returns result when done."""
    ```

    The `run()` method implements the synchronous exploration loop:

    1. **Initialize:** `frame = self._bridge.start()` (or accept pre-started bridge). Track `robot_positions = []`, `current_waypoint_runner = None`, `current_goal = None`, `last_rescan_pos`, `last_voxel_count`, `stuck_counter = 0`, `last_position`.

    2. **Main loop** (`for step in range(config.max_steps)`):

       a. **Update SLAM:** `pose = self._slam.process_frame(frame)`. Insert scan into octomap: `self._octomap.insert_scan(self._slam.get_cloud_points()[-N:], pose[:3, 3])` (use last frame's points). Append `pose[:3, 3].copy()` to `robot_positions`.

       b. **Stuck detection:** Compare `pose[:3, 3]` to `last_position`. If distance < `config.stuck_distance_m`, increment `stuck_counter`. If `stuck_counter >= config.stuck_threshold_steps`, force frontier re-scan, reset counter, clear current path.

       c. **Check re-evaluation trigger:** `should_rescan = False`. If distance from `last_rescan_pos` to current pos > `config.rescan_distance_m` OR `octomap.num_occupied - last_voxel_count > config.rescan_voxel_delta` OR `current_waypoint_runner is None or current_waypoint_runner.is_complete` OR stuck triggered: set `should_rescan = True`.

       d. **Frontier re-evaluation** (if should_rescan):
          - `occupied = self._octomap.get_occupied_voxels()`
          - `frontiers = self._frontier_detector.detect(occupied, np.array(robot_positions))`
          - `grid_2d = project_voxels_to_2d(occupied, config.voxel_resolution, config.z_min, config.z_max)`
          - If no frontiers: `terminated_reason = "no_frontiers"`, break
          - Try to select and plan to a frontier. **Loop through candidates:**
            ```python
            remaining = list(frontiers)
            goal = None
            path = None
            while remaining:
                candidate = self._goal_selector.select(remaining, pose)
                if candidate is None:
                    break
                path = self._path_planner.plan(pose[:3, :3]... , candidate, grid_2d)
                if path is not None:
                    goal = candidate
                    break
                # Remove this unreachable frontier and try next
                remaining = [f for f in remaining if not np.allclose(f.centroid, candidate)]
            ```
          - If no reachable goal found: `terminated_reason = "all_unreachable"`, break
          - Create `WaypointRunner(path, linear_speed=config.linear_speed, angular_speed=config.angular_speed, arrival_threshold=config.waypoint_arrival_threshold)`
          - Update `last_rescan_pos`, `last_voxel_count`
          - Update coverage: `cov, bbox_cov = self._coverage_tracker.update(occupied, len(frontiers))`

       e. **Execute navigation:** If `current_waypoint_runner` and not complete: `linear, angular = current_waypoint_runner.get_velocity(pose)`, `self._bridge.set_velocity(linear, angular)`.

       f. **Step simulation:** `frame = self._bridge.step()`

       g. **Periodic logging:** If `step % config.log_interval_steps == 0`: call `self._coverage_tracker.log(step, ...)`.

       h. **Update last_position** for stuck detection.

    3. **Termination:** If loop ends via max_steps: `terminated_reason = "max_steps"`. Return `self._coverage_tracker.result(step, terminated_reason)`.
