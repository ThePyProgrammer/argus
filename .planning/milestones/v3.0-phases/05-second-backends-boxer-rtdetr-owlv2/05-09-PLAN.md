<objective>
Wave 2: wire the crash fallback handler into DetectorWorkerPool + DetectorWorker (D-03). When a BoxeR subprocess dies or hangs, the pool:
  1. Catches BridgeHangError / SubprocessDiedError raised from the bridge (Plan 05 typed exceptions)
  2. Emits a `crash_fallback` WS message mirroring the SLAM pattern at exploration_loop.py:207
  3. Constructs a fresh YOLOv11Backend per worker, warms it, atomically swaps ref under _swap_lock
  4. Marks the crashed backend unavailable for the session via DetectorRegistry.set_available (D-04)

Purpose: Satisfies DET-MODELS-06. The 5-second budget (SC#3) is the bridge's HANG_TIMEOUT_MS (5000ms) plus ~150ms YOLOv11 warmup — WS message arrives immediately after the exception, so user-visible latency is <5 s even before warmup finishes.

    ```python
    def _dummy_frame_for(self, rid: str) -> "SensorFrame":
        """Return a zero-RGB-and-depth frame sized for this rid's worker.

        Used by on_backend_crash for synchronous warmup of the fallback YOLOv11
        before swap. Kept tiny so warmup is fast (≪1 s). 480×640 matches the
        Phase 1 MuJoCo default frame size.
        """
        from src.bridge.sensor_types import SensorFrame
        return SensorFrame(
            rgb=np.zeros((480, 640, 3), dtype=np.uint8),
            depth=np.zeros((480, 640), dtype=np.float32),
            ground_truth_pose=np.eye(4),
            sim_time=0.0,
        )

    def on_backend_crash(self, crashed_backend: str, reason: str,
                         fallback: str = "yolov11") -> None:
        """D-03 — emit crash_fallback WS + atomically swap to fallback backend.

        Mirror of ``src/exploration/exploration_loop.py:207`` SLAM crash pattern.
        Triggered by DetectorWorker when bridge.send_frame raises
        BridgeHangError or SubprocessDiedError (Plan 05 typed exceptions).

        Steps:
          1. Append crash_fallback message to streaming_viz._message_queue (if set).
          2. Mark crashed_backend unavailable via DetectorRegistry.set_available (D-04).
          3. Construct per-worker fallback instance; warmup; atomically swap ref.

        Exceptions from step 3 are logged but NOT re-raised — a failed fallback
        is still better than leaving the caller thread with a dead bridge.
        """
        _LOGGER.warning(
            "on_backend_crash: crashed=%s reason=%r → fallback=%s",
            crashed_backend, reason, fallback,
        )

        # Step 1 — WS message (same envelope as SLAM crash at exploration_loop.py:207).
        if self._streaming_viz is not None and hasattr(self._streaming_viz, "_message_queue"):
            try:
                self._streaming_viz._message_queue.append({
                    "type": "crash_fallback",
                    "payload": {
                        "subsystem": "detector",
                        "crashed_backend": crashed_backend,
                        "fallback_backend": fallback,
                        "reason": reason,
                    },
                })
            except Exception:  # noqa: BLE001 — never block on viz enqueue failure
                _LOGGER.exception("failed to enqueue crash_fallback message")

        # Step 2 — Session-scoped availability lockout (D-04).
        try:
            DetectorRegistry.set_available(
                crashed_backend, False,
                reason=f"{reason} — restart the coordinator to retry.",
            )
        except Exception:  # noqa: BLE001
            _LOGGER.exception("set_available failed for %s", crashed_backend)

        # Step 3 — Construct + warm fallback per worker, then atomic ref swap.
        try:
            import src.perception.backends  # noqa: F401  — trigger registration
            new_detectors: dict[str, Any] = {}
            for rid in self._workers:
                d = DetectorRegistry.create(fallback)
                d.warmup(self._dummy_frame_for(rid))
                new_detectors[rid] = d
            with self._swap_lock:
                for rid, w in self._workers.items():
                    w._detector = new_detectors[rid]  # atomic attribute write under GIL
                self.backend_name = fallback
            _LOGGER.info("swapped crashed %s → %s across %d workers",
                         crashed_backend, fallback, len(self._workers))
        except Exception:  # noqa: BLE001 — fallback failure is a second-order error
            _LOGGER.exception("fallback construction failed for %s", fallback)
    ```
