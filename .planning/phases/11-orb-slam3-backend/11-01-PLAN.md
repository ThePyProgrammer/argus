```python
class TrackingStatus(Enum):
    OK = "ok"
    LOST = "lost"
    INITIALIZING = "initializing"
    RELOCALIZING = "relocalizing"

@dataclass
class SLAMResult:
    pose: np.ndarray          # (4, 4) float64
    points: np.ndarray        # (N, 3) float64
    colors: np.ndarray        # (N, 3) float64
    metrics: dict = field(default_factory=dict)
    tracking_status: TrackingStatus = TrackingStatus.OK

@runtime_checkable
class SLAMProtocol(Protocol):
    CAPABILITIES: dict
    PARAMETER_SCHEMA: dict
    def process_frame(self, frame: SensorFrame) -> SLAMResult: ...
    def reset(self) -> None: ...
    def get_global_cloud(self) -> tuple[np.ndarray, np.ndarray]: ...
    def get_poses(self) -> list[np.ndarray]: ...
    @property
    def num_frames_processed(self) -> int: ...
```

    2. `@slam_backend(name="orbslam3", display="ORB-SLAM3")` decorator
    3. `CAPABILITIES = {"supports_imu": False, "outputs_dense": True, "supports_loop_closure": True, "supports_stereo": False}`
    4. `PARAMETER_SCHEMA` with properties: nFeatures (int, default 1000, min 100, max 5000, live_tunable=False), scaleFactor (float, default 1.2, min 1.01, max 2.0, live_tunable=False), nLevels (int, default 8, min 1, max 16, live_tunable=False), mode (string, default "rgbd", enum ["rgbd", "monocular"], live_tunable=False)
    5. `__init__(self, intrinsics, nFeatures=1000, scaleFactor=1.2, nLevels=8, mode="rgbd")`:
       - Raise ImportError if not _ORBSLAM3_AVAILABLE
       - Store intrinsics, mode, _last_pose=np.eye(4), _poses=[], _global_points/colors=empty arrays, _num_frames=0
       - Call `_write_config()` to generate temp YAML

       - Call `self._slam.set_use_viewer(False)` and `self._slam.initialize()`
       - Register `atexit.register(self._cleanup_config)` for temp file cleanup
    6. `process_frame(self, frame: SensorFrame) -> SLAMResult`:
       - If mode is "rgbd": call `self._slam.process_image_rgbd(frame.rgb, frame.depth, frame.sim_time)`
       - If mode is "monocular": call `self._slam.process_image_mono(frame.rgb, frame.sim_time)`
       - Get pose via `self._slam.get_frame_pose()` — returns 4x4 numpy or None
       - If pose is None or invalid: return SLAMResult with _last_pose, empty points/colors, tracking_status=LOST
       - Apply coordinate transform: `pose = self._convert_pose(raw_pose)`
       - Store pose, increment _num_frames
       - Generate dense cloud: call `depth_to_pointcloud(frame.depth, frame.rgb, self._intrinsics)` then transform points by pose
       - Get sparse feature count: `sparse_points = self._slam.get_current_points()`, store `len(sparse_points)` in metrics
       - Accumulate into global cloud arrays (copy to prevent mutable reference bugs, same as ICPBackend)
       - Return SLAMResult(pose=pose, points=frame_points, colors=frame_colors, metrics={"sparse_feature_count": N, "tracking_status_raw": ...}, tracking_status=TrackingStatus.OK)
    7. Static coordinate transform `T_MUJOCO_FROM_OPTICAL`:

    9. `reset()`: Shutdown and reinitialize ORB-SLAM3 system. Clear _poses, _global_points, _global_colors, _num_frames. Clean up old temp config, write new one.
    10. `get_global_cloud()`, `get_poses()`, `num_frames_processed` — same pattern as ICPBackend
    11. `_cleanup_config()`: Remove temp YAML file if it exists (called by atexit and reset)

    1. Create `scripts/download_orbslam3_vocab.sh`:
       ```bash
       #!/usr/bin/env bash
       set -euo pipefail

       VOCAB_DIR="$(cd "$(dirname "$0")/.." && pwd)/models/orbslam3"
       VOCAB_FILE="$VOCAB_DIR/ORBvoc.txt"
       VOCAB_URL="https://github.com/UZ-SLAMLab/ORB_SLAM3/raw/master/Vocabulary/ORBvoc.txt.tar.gz"
       EXPECTED_SIZE_MB=40

       mkdir -p "$VOCAB_DIR"

       if [ -f "$VOCAB_FILE" ]; then
           echo "[OK] ORBvoc.txt already exists at $VOCAB_FILE"
           exit 0
       fi

       echo "Downloading ORB-SLAM3 vocabulary (~${EXPECTED_SIZE_MB}MB compressed)..."
       TMPFILE=$(mktemp)
       curl -fSL "$VOCAB_URL" -o "$TMPFILE"

       echo "Extracting..."
       tar -xzf "$TMPFILE" -C "$VOCAB_DIR"
       rm -f "$TMPFILE"

       if [ -f "$VOCAB_FILE" ]; then
           SIZE=$(du -m "$VOCAB_FILE" | cut -f1)
           echo "[OK] ORBvoc.txt downloaded (${SIZE}MB) to $VOCAB_FILE"
       else
           echo "[ERROR] Extraction failed — ORBvoc.txt not found after extracting"
           exit 1
       fi
       ```
