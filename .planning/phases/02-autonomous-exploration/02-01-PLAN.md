    Define `FrontierCluster` dataclass:
    ```python
    @dataclass
    class FrontierCluster:
        centroid: np.ndarray    # (3,) float64 world coordinates
        voxel_count: int        # number of voxels in this cluster
        voxels: np.ndarray      # (K, 3) int grid indices of cluster voxels
    ```

    Implement `FrontierDetector` class:
    - `__init__(self, resolution: float = 0.1, min_cluster_size: int = 5)` -- store resolution and min cluster size.
    - `detect(self, occupied_voxels: np.ndarray, robot_positions: np.ndarray) -> list[FrontierCluster]`:
      - `occupied_voxels`: (N, 3) float64 from `OctoMapBuilder.get_occupied_voxels()`
      - `robot_positions`: (M, 3) float64 positions the robot has visited (for defining the "observed" region)
      - Return early with `[]` if occupied_voxels is empty or has fewer than min_cluster_size rows
      - Convert world coords to grid indices: `indices = ((occupied_voxels - grid_min) / resolution).astype(int)` where `grid_min = occupied_voxels.min(axis=0) - resolution * 5`
      - Build `occupied_set = set(map(tuple, indices))` for O(1) lookup
      - Scan each voxel's 26 neighbors (precompute offsets as list of 26 (dx,dy,dz) tuples excluding (0,0,0)). If any neighbor is NOT in occupied_set, this voxel is a frontier voxel.
      - Cluster frontier voxels using BFS on 26-connectivity: use `collections.deque`, visit neighbors that are also in the frontier set.
      - Filter clusters by `min_cluster_size`.
      - For each surviving cluster, compute centroid in world coords: `grid_min + np.mean(cluster_indices, axis=0) * resolution`
      - Return list of FrontierCluster objects sorted by voxel_count descending.

    - `select(self, frontiers: list[FrontierCluster], robot_pose: np.ndarray) -> np.ndarray | None`:

      - Return `None` if frontiers is empty
      - If strategy == "nearest": return centroid of cluster with minimum Euclidean distance to robot position
      - If strategy == "largest": return centroid of cluster with maximum voxel_count
      - Return centroid as (3,) float64 array

    **Create `src/exploration/occupancy_grid.py`:**

    Define cell values as module constants:
    ```python
    CELL_UNKNOWN = -1
    CELL_FREE = 0
    CELL_OCCUPIED = 100
    ```

    Define `OccupancyGrid2D` dataclass:
    ```python
    @dataclass
    class OccupancyGrid2D:
        grid: np.ndarray        # (H, W) int8 array: CELL_FREE, CELL_OCCUPIED, CELL_UNKNOWN
        resolution: float       # meters per cell
        origin: np.ndarray      # (2,) world coordinates of grid[0,0]
        width: int              # grid columns
        height: int             # grid rows
    ```

    Add methods on `OccupancyGrid2D`:
    - `world_to_grid(self, xy: np.ndarray) -> tuple[int, int]`: Convert (2,) world XY to grid (row, col). Formula: `col = int((xy[0] - origin[0]) / resolution)`, `row = int((xy[1] - origin[1]) / resolution)`. Clamp to grid bounds.
    - `grid_to_world(self, row: int, col: int) -> np.ndarray`: Convert grid (row, col) to (2,) world XY center. Formula: `x = origin[0] + (col + 0.5) * resolution`, `y = origin[1] + (row + 0.5) * resolution`.
    - `is_free(self, row: int, col: int) -> bool`: Return True if cell is CELL_FREE and within bounds.

    Implement `project_voxels_to_2d(occupied_voxels: np.ndarray, resolution: float, z_min: float = 0.0, z_max: float = 2.0, padding: int = 10) -> OccupancyGrid2D`:
    - Filter voxels by height: keep voxels where `z_min <= z <= z_max`
    - If no voxels remain, return a small 1x1 grid with CELL_UNKNOWN
    - Compute XY bounding box of filtered voxels with `padding` cells extra on each side
    - Create grid of shape (rows, cols) initialized to `CELL_UNKNOWN`
    - For each filtered voxel, compute grid cell and mark as `CELL_OCCUPIED`
    - Mark cells as `CELL_FREE` using dilation: for each occupied cell, all 8-connected neighbors that are UNKNOWN and not occupied become FREE. Repeat dilation `max(3, int(1.0 / resolution))` times to create a free-space band around obstacles. This is the simplified free-space model (Claude's discretion -- simpler than ray-casting, adequate for A*).
    - Return `OccupancyGrid2D` with computed origin, resolution, dimensions.

    **Create `src/exploration/path_planner.py`:**

    Implement `PathPlanner` class:
    - `__init__(self, unknown_cost: float = 5.0)`: cost multiplier for traversing UNKNOWN cells (discourage but allow).
    - `plan(self, start_world: np.ndarray, goal_world: np.ndarray, grid: OccupancyGrid2D) -> list[np.ndarray] | None`:
      - Convert start_world[:2] and goal_world[:2] to grid coords via grid.world_to_grid()
      - If start or goal cell is OCCUPIED, return None
      - Run A* with 8-connected neighbors (diagonal cost = sqrt(2), cardinal cost = 1.0)
      - UNKNOWN cells are traversable but cost `unknown_cost` multiplier
      - OCCUPIED cells are impassable
      - Use `heapq` priority queue with octile distance heuristic: `h = max(|dx|, |dy|) + (sqrt(2) - 1) * min(|dx|, |dy|)`
      - On success, convert grid path to world coordinate waypoints via grid.grid_to_world()
      - Simplify path: keep every Nth waypoint (N = `max(1, int(1.0 / grid.resolution))`) to produce coarse waypoints ~1m apart. Always keep start and goal.
      - Return list of (3,) float64 waypoints (Z set to 0.0 since this is ground-plane navigation)
      - Return None if no path found (goal unreachable)

    The A* implementation should be ~80 lines, ported from the DimOS `min_cost_astar()` pattern: heapq-based, 8-connected, with cost thresholds for occupied cells.

    - Test A* finds path on open grid, returns None on fully blocked grid, finds path through gap.
    - Verify returned waypoints are (3,) float64 arrays in world coordinates.
