## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env config -> ControllerRegistry | Configured controller id selects a controller instance for the environment. |
| controller result -> env `data.ctrl` | Controller-produced target reaches the environment's MuJoCo control sink. |
| env info -> future evaluation artifacts | Metadata is used later to attribute benchmark results. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-2-02 | Denial of Service | `ArgusGo2Env.__init__` selection | mitigate | Unavailable placeholder ids fail during env construction via `ControllerRegistry.create`, before any run. |
| T-2-03 | Tampering | `ArgusGo2Env.step` controller dispatch | mitigate | Use shared dispatch/target validation before `data.ctrl` writes; preserve pre-mutation invalid-action rejection. |
| T-2-05 | Repudiation | `ArgusGo2Env._info` | mitigate | Include full `controller_metadata` at reset and compact `controller_id`/`action_mode` per step. |
</threat_model>
