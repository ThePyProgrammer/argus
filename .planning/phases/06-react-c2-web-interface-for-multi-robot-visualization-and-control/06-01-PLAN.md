- Constructor: `__init__(self, connection_manager: ConnectionManager, robot_ids: list[str])` stores cm, robot_ids, initializes `_last_voxel_set: set = set()`, `_last_full_sync: float = 0.0`, `_full_sync_interval: float = 10.0`, `_color_mode: str = "robot_tint"`, `_start_time: float = time.monotonic()`
- Method: `update(self, merged_voxels, robot_data, frontier_cells=None, voronoi_midpoint=None, voronoi_direction=None, total_coverage=0.0, merge_count=0) -> None` -- SAME SIGNATURE as MultiRobotVisualizer.update()
  - Compute cloud delta via `compute_cloud_delta(merged_voxels, self._last_voxel_set)`. If delta non-empty, queue `{"type": "cloud_delta", "payload": {"positions": delta.tolist()}}`. Check if full sync needed (time.monotonic() - _last_full_sync > _full_sync_interval); if so, queue `{"type": "cloud_full", "payload": {"positions": merged_voxels.tolist()}}`
  - For each robot in robot_data: queue `{"type": "pose_update", "robot_id": rid, "payload": {"position": pose[:3,3].tolist(), "rotation": pose[:3,:3].flatten().tolist()}}`
  - For each robot: queue `{"type": "trajectory", "robot_id": rid, "payload": {"positions": [[p[:3,3].tolist() for p in trajectory]], "alphas": [list of ints 0-255 fading]}}` -- last 50 positions max
  - For each robot: encode camera frame via `encode_camera_frame(rid, robot_data[rid]["frame"].rgb)` and queue as binary
  - Queue stats: `{"type": "stats", "payload": {"total_coverage": total_coverage, "merge_count": merge_count, "elapsed": elapsed, "robots": {rid: {"coverage_pct": data["coverage_pct"], "voxel_count": len(data["local_voxels"]), "action": "exploring"} for rid, data in robot_data.items()}}}`
  - Color mode support: if `_color_mode == "robot_tint"`, cloud_delta payload includes `"colors"` as list of per-voxel RGB from robot palette. If `"true_rgb"`, colors come from camera data (placeholder -- just white for now since merged voxels don't carry color)
- Method: `set_color_mode(self, mode: str)` -- sets `_color_mode` to "robot_tint" or "true_rgb"
- Method: `get_pending_messages(self) -> list[dict | bytes]` -- returns queued messages and clears queue. This allows the async server to pull messages from the sync viz without crossing thread boundaries unsafely
- Internal: `_message_queue: list[dict | bytes] = []` -- accumulated during update(), drained by server
