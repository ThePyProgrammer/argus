  appendDelta(newPositions: number[][], newColors?: number[][]): void {

Key details:
- Pre-allocate 200k points (200000 * 3 * 4 = 2.4MB position buffer + 600KB color buffer)
- `updateFull`: reset currentCount to 0, write all positions, update draw range
- `appendDelta`: write at offset currentCount * 3, increment currentCount
- Both methods: set `posAttr.needsUpdate = true`, `colAttr.needsUpdate = true`, call `geometry.computeBoundingSphere()`
- Default color if none provided: white (255, 255, 255)

Create `src/c2-frontend/src/hooks/useSceneLoader.ts`:
- Takes a `THREE.Scene` as argument
- Attempts to load `/assets/scene.glb` using `THREE.GLTFLoader` from `three/addons/loaders/GLTFLoader.js`
- On success: adds loaded scene to Three.js scene graph
- On error (404): logs warning, does nothing (graceful fallback to empty scene -- GLB may not exist yet)
- Returns `{ loading: boolean, error: string | null }`
