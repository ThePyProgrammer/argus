  <action>
Create a new file `frontend/vitest.config.ts` with these exact contents (9 lines):

```typescript
/// <reference types="vitest" />
import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    globals: true,
    environment: 'jsdom',
    include: ['src/**/__tests__/**/*.test.ts', 'src/**/*.test.ts'],
  },
});
```

Rationale for jsdom (per Pitfall #1): the D-03 test in Plan 11 imports detectorStore + slamStore, which transitively pull React types through zustand. Pure 'node' env fails at runtime with `ReferenceError: document is not defined` once component tests land in later phases. jsdom keeps Plan 11's test and any future component test working with zero re-config.

DO NOT add `setupFiles`, `coverage`, or any other test config option — keep the config minimal.
