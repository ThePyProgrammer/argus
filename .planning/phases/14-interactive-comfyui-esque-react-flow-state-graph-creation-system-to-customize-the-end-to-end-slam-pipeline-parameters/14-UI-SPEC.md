# Phase 14 — UI Design Contract

> Visual and interaction contract for the ComfyUI-style React Flow pipeline graph editor. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (inline React styles, consistent with Phases 6-13) |
| Icon library | none (Unicode symbols + inline SVG, consistent with existing codebase) |
| Font | system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif |

**Note:** Project uses zero external CSS frameworks. All styling is inline React CSSProperties objects. Phase 14 continues this pattern. React Flow (`@xyflow/react` v12) provides its own base styles which are the sole CSS import for graph rendering.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Port gaps, inline icon margins, badge margins |
| sm | 8px | Intra-node padding, compact element spacing |
| md | 12px | Node body padding, palette item padding |
| lg | 16px | Section padding, inspector panel gutter |
| xl | 24px | Panel headers, node palette category spacing |
| 2xl | 32px | Major section breaks between inspector sections |
| 3xl | 48px | Not used in this phase |

Exceptions:
- Node port handles: 12px diameter (centered on node edge)
- Minimap: 160x120px fixed in bottom-right corner with 12px margin from edges
- Node minimum width: 220px
- Node maximum width: 320px
- Inspector panel width: 320px (matches existing sidebar width)

## Layout Contract

### View Toggle Behavior

The hero area (`viewer-area` in App.css grid) switches between two modes:

| Mode | Content | Toggle Label |
|------|---------|-------------|
| 3D Viewer (default) | `<SceneViewer />` | "3D Viewer" (active) |
| Pipeline Editor | `<PipelineEditor />` | "Pipeline Editor" (active) |

Toggle position: Top-left corner of hero area, z-index above canvas, 8px margin from top-left.
Toggle style: Two adjacent buttons, 32px height, active button uses accent background (#4fc3f7) with dark text, inactive uses #2a2a4a with #888 text.

### Pipeline Editor Layout (when active)

```
+------------------+---------------------+-----------------+
|   Node Palette   |   React Flow        |  Node Inspector |
|   (240px)        |   Canvas            |  (320px)        |
|                  |   (flex: 1)         |                 |
|   [Search...]    |                     |  [Node Title]   |
|   > Sensors      |    +---+   +---+    |  [All params]   |
|   > SLAM         |    |   |---|   |    |  [Slider...]    |
|   > Mergers      |    +---+   +---+    |  [Toggle...]    |
|   > Filters      |                     |                 |
|   > Splitters    |              minimap |                 |
|   > Parameters   |              [====] |                 |
+------------------+---------------------+-----------------+
|              Apply Bar (full width, 48px height)          |
|  [Preset: v] [Modified badge]  [Validate] [Apply Pipeline]|
+-----------------------------------------------------------+
```

- Node Palette: collapsible via toggle arrow. When collapsed: 0px width, palette hidden.
- Node Inspector: only visible when a node is selected. When no selection: 0px width, space given to canvas.
- Apply Bar: always visible when in Pipeline Editor mode. Fixed to bottom of editor area.

### Node Visual Structure

```
+-----------------------------------+
| [Category Color Header Bar 28px]  |
| [Icon] Node Title     [Status]    |
+-----------------------------------+
| o Image   [port label]            |  <- input port (left side)
| o IMU     [port label]            |
|                                   |
|  voxel_size: [====0.05====]      |  <- inline primary param
|  max_iter:   [====100=====]      |  <- inline primary param
|                                   |
|            PointCloud o           |  <- output port (right side)
|            Pose       o           |

```

- Header bar: 28px tall, category color fill, 8px horizontal padding.
- Node body: #1e1e32 fill, 1px solid #2a2a4a border, 8px border-radius.
- Selected node: 2px solid #4fc3f7 border instead of #2a2a4a.
- Input ports: left edge, vertically distributed with 20px spacing.
- Output ports: right edge, vertically distributed with 20px spacing.
- Port handle: 12px diameter circle (or diamond/square per type), centered on node edge.
- Inline params: only params with `primary: true` in schema. Rendered as compact 24px-tall sliders or mini-toggles.
- Status badge: top-right of header. 8px circle. Green (#2ecc71) = processing, gray (#666) = idle, red (#d32f2f) = error, pulsing blue (#4fc3f7) = initializing.

## Interaction Contracts

### Drag-to-Connect

1. User mousedown on output port handle.
2. A preview edge renders from source port to cursor, colored by source data type.
3. Compatible target ports glow (scale 1.3 pulse, full opacity). Incompatible ports dim (opacity 0.2).
4. On mouseup over compatible port: edge created with snap animation (100ms ease-out).
5. On mouseup over incompatible port or empty canvas: preview edge disappears, no connection made.
6. Validation: only one edge per input port. Multiple edges from one output port allowed (fan-out).

### Node Selection

1. Click node: selects it, opens NodeInspector on right with full params.
2. Click canvas: deselects node, hides NodeInspector.
3. Multi-select: Shift+click or rubber-band drag. NodeInspector shows "N nodes selected" (no param editing).

### Node Palette Drag-to-Add

1. User drags a node type from NodePalette onto canvas.
2. Ghost node follows cursor at 50% opacity.
3. On drop: node instantiated at drop position with default parameter values from JSON Schema.

### Right-Click Context Menu

1. Right-click on canvas: menu with "Add Node" (opens searchable submenu), "Paste", "Select All".
2. Right-click on node: menu with "Delete", "Duplicate", "Disconnect All".
3. Right-click on edge: menu with "Delete Edge".

### Apply Pipeline Flow

1. User modifies graph (add/remove nodes, change connections, edit params).
2. ApplyBar shows "Modified" badge (orange dot + text) when graph differs from last applied config.
3. User clicks "Apply Pipeline".
4. If graph has validation errors (unconnected required ports, cycles): show inline error list in ApplyBar, block apply.
5. If valid: ConfirmModal opens: "Apply pipeline configuration? This will restart the simulation."
6. On confirm: POST /api/pipeline/apply with serialized graph JSON. RestartOverlay shows during restart.
7. On success: "Modified" badge clears. Node status badges begin updating from running pipeline.
8. On failure: CrashToast with error message.

### Preset Management

1. PresetSelector dropdown shows: built-in presets (read-only, italic label), user presets, and "Save Current..." option.
2. Loading a preset: replaces current graph nodes/edges. If graph was modified, ConfirmModal: "Discard unsaved changes?"
3. Saving: text input for preset name. Overwrites if name exists (with confirmation).
4. Built-in presets: "Default ICP" (Sensor->ICP->ICP Union->Viz), "PGO High Quality" (Sensor->ICP->Open3D PGO->Viz), "Comparison Mode" (Sensor->Splitter->[ICP, ORB-SLAM3]->Combiner->Viz).

### Edge Animation (when pipeline is running)

- Animated flowing dots along edges: 3px dots at 60% opacity of edge color, moving at 40px/s in data direction.
- Throughput label: centered on edge midpoint, 10px font, showing "N fps" when data is flowing.
- Idle edges (no data flowing): static, #4a4a6a color, no dots.

## State Contracts

### pipelineStore Shape

```typescript
interface PipelineStore {
  // Graph state
  nodes: PipelineNode[];           // React Flow nodes with custom data
  edges: PipelineEdge[];           // React Flow edges with type info
  selectedNodeId: string | null;

  // Preset state
  activePreset: string | null;     // null = custom unsaved
  availablePresets: PresetInfo[];   // { name, builtIn, nodeCount }
  isDirty: boolean;                // graph differs from last applied

  // Validation
  validationErrors: ValidationError[];  // { nodeId?, message }
  isValid: boolean;                     // derived: validationErrors.length === 0

  // Pipeline status (from backend WS)
  isApplying: boolean;
  nodeStatuses: Record<string, 'idle' | 'processing' | 'error' | 'initializing'>;
  edgeThroughputs: Record<string, number>;  // edge id -> fps

  // Actions
  setNodes: (nodes: PipelineNode[]) => void;
  setEdges: (edges: PipelineEdge[]) => void;
  onNodesChange: OnNodesChange;     // React Flow callback
  onEdgesChange: OnEdgesChange;     // React Flow callback
  onConnect: OnConnect;             // React Flow callback
  selectNode: (id: string | null) => void;
  addNode: (type: string, position: XYPosition) => void;
  removeNode: (id: string) => void;
  loadPreset: (name: string) => void;
  savePreset: (name: string) => void;
  validate: () => void;
  serializeForApply: () => PipelineConfig;
  markApplied: () => void;
  setNodeStatus: (nodeId: string, status: string) => void;
  setEdgeThroughput: (edgeId: string, fps: number) => void;
}
```

## Accessibility Minimums

| Concern | Contract |
|---------|----------|
| Keyboard nav | Tab through nodes on canvas. Enter to select. Delete key to remove selected. Arrow keys to move selected node. |
| Port connection | Ports reachable via Tab within node. No keyboard-only connection mechanism (mouse required for drag-to-connect, consistent with ComfyUI/React Flow standard). |
| Focus visible | 2px solid #4fc3f7 outline on focused interactive elements (buttons, inputs, node handles). |
| Color contrast | All text meets WCAG AA (4.5:1 minimum). #e0e0e0 on #1e1e32 = 9.7:1. #888 on #1e1e32 = 4.6:1. |
| Screen reader | Node palette items have aria-label with node type and category. Status badges have aria-live="polite" for status changes. |
| Reduced motion | Edge animations respect `prefers-reduced-motion: reduce` -- replace flowing dots with static dashed line. |
