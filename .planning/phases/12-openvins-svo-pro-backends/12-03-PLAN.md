Implement the OpenVINS visual-inertial SLAM backend and its C++ subprocess harness.

The C++ harness wraps OpenVINS's VioManager and speaks the ZMQ wire protocol.

Create the C++ harness that wraps OpenVINS and speaks the ZMQ wire protocol. This code will NOT be compiled in CI (requires OpenVINS C++ libs installed) but provides the complete implementation for users who build OpenVINS from source.

1. Create extern/openvins_harness/CMakeLists.txt:
```cmake
cmake_minimum_required(VERSION 3.14)
project(openvins_harness LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)

# Find dependencies
find_package(Eigen3 3.3 REQUIRED)
find_package(cppzmq REQUIRED)  # Header-only ZMQ C++ bindings
find_package(msgpack-cxx REQUIRED)

# OpenVINS -- installed via `make install` from ov_msckf build
find_library(OV_MSCKF_LIB ov_msckf_lib REQUIRED)
find_path(OV_MSCKF_INCLUDE open_vins REQUIRED)

add_executable(openvins_harness main.cpp)
target_include_directories(openvins_harness PRIVATE ${OV_MSCKF_INCLUDE})
target_link_libraries(openvins_harness
    PRIVATE
    ${OV_MSCKF_LIB}
    Eigen3::Eigen
    cppzmq
    msgpack-cxx
)
```

2. Create extern/openvins_harness/main.cpp implementing:
   - Parse CLI args: `--config <path>` `--zmq <ipc_endpoint>`
   - Connect ZMQ PAIR socket to the endpoint
   - Initialize OpenVINS VioManager from config
   - Main loop:
     a. Receive multipart [header, rgb, depth, imu?]
     b. Unpack msgpack header to get shapes, dtypes, n_imu
     c. Feed IMU readings to vio->feed_measurement_imu() (each reading individually)
     d. Feed image to vio->feed_measurement_monocular() (or stereo if configured)
     e. Get state: vio->get_state() -- extract position and quaternion
     f. Build 4x4 pose matrix from position + quaternion
     g. Pack response as msgpack: {pose: raw_bytes, status: "ok"|"initializing"|"lost", time_ms: float}
     h. Send response

   - Error handling: catch exceptions from OpenVINS, send status="lost" on failure
   - Signal handling: clean shutdown on SIGTERM/SIGINT

Key OpenVINS API calls (from research):
```cpp
#include "ov_msckf/VioManager.h"
#include "ov_msckf/VioManagerOptions.h"

// Init
auto params = ov_msckf::VioManagerOptions();
params.load_print_simulation(config_path);  // Load from YAML
auto vio = std::make_shared<ov_msckf::VioManager>(params);

// Feed IMU (for each reading)
ov_core::ImuData imu;
imu.timestamp = reading_ts;
imu.wm = Eigen::Vector3d(gx, gy, gz);
imu.am = Eigen::Vector3d(ax, ay, az);
vio->feed_measurement_imu(imu);

// Feed image
ov_core::CameraData cam;
cam.timestamp = frame_ts;
cam.sensor_ids.push_back(0);
cam.images.push_back(cv_image);
vio->feed_measurement_camera(cam);

// Get pose
auto state = vio->get_state();
Eigen::Vector3d pos = state->_imu->pos();
Eigen::Matrix3d rot = state->_imu->Rot();
// Build 4x4: [rot, pos; 0 0 0 1]
```
