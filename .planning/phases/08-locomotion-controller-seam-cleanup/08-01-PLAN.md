<objective>
Resolve the multi-robot bridge seam audit debt for LOC-CTRL-04 by making the current platform-runtime boundary deliberate and by replacing shape-only indexed control writes with generic validation-before-mutation behavior modeled on the shared controller-dispatch helper.

Purpose: Preserve MultiRobotBridge's platform abstraction for Go2 and non-Go2 runtimes while eliminating the unsafe duplicated control-write path flagged in the v4.0 audit.
Output: Bridge-level regressions and a MultiRobotBridge control loop that validates output shape, finite values, index count, duplicate indices, and index bounds before mutating `data.ctrl`, without forcing non-Go2 platform controllers through Go2's 12-target helper.
</objective>

From `src/locomotion/controller_dispatch.py`:
```python
def apply_controller_target(data: Any, target: Sequence[float] | np.ndarray, ctrl_indices: Sequence[int] | None = None) -> np.ndarray:
    """Validate and apply one Go2 controller target to a control sink.

    With indices supplied, exactly twelve actuator indices are required and each
    target element is written to the paired actuator slot. All validation is done
    before the first data.ctrl mutation.
    """
```

Current direct-write anti-pattern in `src/bridge/multi_bridge.py` to replace:
```python
ctrl = self._controllers[robot_id].compute(command, state, self._dt)
if ctrl.shape != (len(self._ctrl_indices[robot_id]),):
    raise RuntimeError(...)
for i, act_id in enumerate(self._ctrl_indices[robot_id]):
    self._data.ctrl[act_id] = ctrl[i]
```

Chosen Phase 8 boundary: keep `MultiRobotBridge` as the platform-runtime boundary that constructs controllers with `self._platform.make_controller(rid)`, because it supports non-Go2 platform controllers and runtime health semantics. Close the unsafe seam by adding a bridge-local helper named exactly `_apply_platform_controller_target(self, robot_id: str, ctrl: np.ndarray) -> None` that copies the all-or-nothing indexed validation pattern from `apply_controller_target()` while validating target length against `len(self._ctrl_indices[robot_id])` rather than requiring Go2's 12-element target. Keep `apply_controller_target()` referenced as the source pattern for all-or-nothing indexed validation; do not call it unconditionally for non-Go2 platform targets.

| MultiRobotBridge ctrl_indices -> MuJoCo data.ctrl | Per-robot actuator indices choose which physics control slots can be mutated. |
