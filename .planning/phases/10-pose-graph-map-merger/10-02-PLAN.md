Class `Open3DPGOStrategy`:
- `CAPABILITIES = {"supports_loop_closure": True, "incremental": False}`
- `PARAMETER_SCHEMA` with properties:
  - `max_correspondence_distance` (number, default 0.15, min 0.01, max 1.0, description "Max ICP correspondence distance (m)", live_tunable False)
  - `edge_prune_threshold` (number, default 0.25, min 0.01, max 1.0, description "Edge prune threshold for PGO", live_tunable False)
  - `loop_closure_fitness_threshold` (number, default 0.3, min 0.05, max 0.9, description "Min ICP fitness for loop closure acceptance", live_tunable False)
  - `loop_closure_interval` (integer, default 5, min 1, max 50, description "Run loop closure every N merge cycles", live_tunable True)
  - `min_points_for_icp` (integer, default 50, min 10, max 1000, description "Min points in cloud for ICP registration", live_tunable False)

- `__init__(self, max_correspondence_distance=0.15, edge_prune_threshold=0.25, loop_closure_fitness_threshold=0.3, loop_closure_interval=5, min_points_for_icp=50)` stores params, initializes `_merge_count = 0`, `_last_merged_voxels = np.empty((0,3))`, `_last_merged_cloud = o3d.geometry.PointCloud()`

- `merge(self, robot_data: dict[str, RobotMapData]) -> MergeResult`:
  1. If 0 or 1 robot: return trivially (single robot returns its own data as MergeResult)
  2. Build pose graph: for each robot, add PoseGraphNode per pose. Add odometry edges (consecutive poses within same robot, `uncertain=False`). Compute relative transform as `np.linalg.inv(poses[i-1]) @ poses[i]`. Compute information matrix using `get_information_matrix_from_point_clouds` when frame_clouds available, else use `np.eye(6)`.
  3. Use offset ranges for node IDs: robot_a starts at 0, robot_b starts at len(robot_a_poses), etc. Track `robot_node_ranges: dict[str, tuple[int, int]]`.
  4. Every `loop_closure_interval` merges: attempt inter-robot loop closure. For each pair of robots, take their latest frame cloud, create PointCloud objects, run `registration_icp(cloud_a, cloud_b, max_correspondence_distance, np.eye(4), TransformationEstimationPointToPlane())`. If `result.fitness >= loop_closure_fitness_threshold` AND both clouds have >= `min_points_for_icp` points: add PoseGraphEdge with `uncertain=True`. Else: add edge with identity transform and low information (fallback).
  5. Run `global_optimization(pose_graph, GlobalOptimizationLevenbergMarquardt(), GlobalOptimizationConvergenceCriteria(), GlobalOptimizationOption(...))`.
  6. Extract optimized poses from graph nodes. Re-project frame_clouds using optimized poses: for each robot, for each frame, transform `frame_clouds[i]` by `optimized_poses[i][:3,:3] @ cloud.T + optimized_poses[i][:3,3]`. Union-merge into voxels via voxel downsampling.
  7. Build merged_cloud from merged_voxels.
  8. Increment `_merge_count`, store `_last_merged_voxels` and `_last_merged_cloud`.
  9. Return MergeResult with metrics: `{"strategy": "pgo_open3d", "graph_nodes": N, "graph_edges": M, "loop_closures_found": X, "loop_closure_fallbacks": Y}`.

- `reset(self)`: clear `_merge_count = 0`, `_last_merged_voxels = np.empty((0,3))`, `_last_merged_cloud = o3d.geometry.PointCloud()`
- Properties: `last_merged_voxels`, `last_merged_cloud` returning stored values.

Helper function `_detect_loop_closure(cloud_a, cloud_b, max_corr_dist, fitness_threshold) -> tuple[bool, np.ndarray, float]`: returns (success, transform, fitness). Guards against clouds with < min_points_for_icp points by returning (False, np.eye(4), 0.0).

Helper function `_voxel_downsample_points(points: np.ndarray, resolution: float) -> np.ndarray`: grid-based deduplication matching MapMerger.merge_voxels logic.

  - Create noise models: `PRIOR_NOISE = gtsam.noiseModel.Diagonal.Sigmas(np.array([rot_sigma]*3 + [trans_sigma]*3))` for prior, odom, loop closure
  - Create `gtsam.ISAM2(params)` where params has `relinearizeThreshold=0.1`, `relinearizeSkip=1`

- `merge(self, robot_data: dict[str, RobotMapData]) -> MergeResult`:
  1. Build incremental factor graph: `gtsam.NonlinearFactorGraph()` and `gtsam.Values()`
  2. For each robot, assign key range using `gtsam.symbol(ord(robot_id[-1]), frame_idx)` pattern (maps 'a'->97, 'b'->98 etc.) to avoid collisions
  3. For first pose of first robot: add PriorFactorPose3 with PRIOR_NOISE
  4. For consecutive poses within each robot: add BetweenFactorPose3 with relative transform and ODOM_NOISE
  5. Every `loop_closure_interval` merges: attempt loop closure between robots using same ICP detection as Open3D strategy (reuse `_detect_loop_closure` logic, or inline similar code using `o3d.pipelines.registration.registration_icp`). If successful: add BetweenFactorPose3 with LOOP_CLOSURE_NOISE. Else: add with fallback identity transform and inflated noise.
  6. Insert initial values: `initial.insert(key, gtsam.Pose3(pose_matrix))`
  7. `self._isam.update(graph, initial)` -- incremental update
  8. `result = self._isam.calculateEstimate()`
  9. Extract optimized poses, re-project frame_clouds, union-merge voxels
  10. Increment `_update_count`, `_merge_count`, store last_merged
  11. Return MergeResult with metrics: `{"strategy": "pgo_gtsam", "isam2_updates": _update_count, "loop_closures_found": X, "loop_closure_fallbacks": Y}`

- `reset(self)`: re-create iSAM2 instance, reset counters and key ranges
- Properties: `last_merged_voxels`, `last_merged_cloud`
