# Phase 9 — UI Design Contract

> Visual and interaction contract for the SLAM algorithm picker, parameter tuning panel, confirmation modal, and restart overlay. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (vanilla React with inline styles) |
| Icon library | none (Unicode characters: lightning bolt U+26A1, lock U+1F512, arrows U+25BC/U+25B6) |
| Font | system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif (inherited from App.css body rule) |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, gap between pill badges, axis label margin |
| sm | 8px | Compact element spacing, button padding vertical, flex gaps between controls |
| md | 12px | Section padding (ControlPanel outer padding), collapsible section margins |
| lg | 16px | Sidebar header padding, gap between stats items, dropdown item padding horizontal |
| xl | 24px | Empty state padding, modal card padding |
| 2xl | 32px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions: 6px used for `marginBottom` between robot cards and flex gaps in existing components. 10px used for `marginBottom` and `marginTop` in ControlPanel sections. These are pre-existing patterns that new components must match for visual consistency. New components use 6px and 10px where they sit adjacent to existing ControlPanel elements to avoid visual discontinuity.

Source: Extracted from ControlPanel.tsx, Sidebar.tsx, RobotCard.tsx measured values.

The 14px/700 heading in Sidebar.tsx header is not replicated in Phase 9 -- this phase adds panel sections, not page headings.

## Component Inventory

### 1. AlgorithmSection

**Location:** Inside ControlPanel.tsx, positioned between the scene/color toggle buttons and the Restart section.

**Behavior:** Collapsible section using the existing click-to-toggle pattern with triangle indicators. Expanded by default on mount. Contains the AlgorithmDropdown, CapabilityBadges for active backend, and ParameterPanel.

**Visual spec:**
- Section header: `SLAM ALGORITHM` in 12px/600/#888, matching "CLOUD CONFIG" header
- Collapse indicator: 10px triangle (U+25BC expanded, U+25B6 collapsed)
- Top border: `1px solid #2a2a4a` matching other section dividers
- Padding top: 10px (matching Cloud Config section)
- Margin top: 12px

### 2. AlgorithmDropdown

**Type:** Custom div-based dropdown (not native `<select>`).

**Trigger element:**
- Full-width div with border `1px solid #444`, border-radius 4px
- Background: `#12122a`
- Padding: 8px 12px
- Display: flex, justify-content: space-between, align-items: center
- Left side: active backend display name in 13px/400/#e0e0e0
- Right side: chevron indicator (U+25BC) in 10px/#888
- Cursor: pointer
- On hover: border color transitions to `#2ecc71`

**Dropdown list (open state):**
- Position: absolute, full-width, below trigger
- Background: `#12122a`
- Border: `1px solid #2a2a4a`
- Border-radius: 0 0 4px 4px
- Z-index: 100
- Max-height: 240px, overflow-y: auto
- Box-shadow: `0 4px 12px rgba(0, 0, 0, 0.4)`

**Dropdown item (available):**
- Padding: 8px 12px
- Cursor: pointer
- On hover: background `#222244`
- Display name: 13px/400/#e0e0e0
- Capability badges: inline after name, wrapped

**Dropdown item (unavailable):**
- Same padding
- Cursor: not-allowed
- Opacity: 0.4
- Name: 13px/400/#555
- Title attribute (native tooltip): reason string from backend (e.g., "orbslam3-python not installed")
- Pointer-events: none on the click handler (do not disable the element itself so tooltip still shows)

**Dropdown item (active/selected):**
- Left border: 2px solid #2ecc71
- Background: `rgba(46, 204, 113, 0.08)`

**Keyboard:** Escape closes. Click-outside closes (document click listener, removed on unmount).

### 3. CapabilityBadge

**Type:** Inline span pill element.

**Visual spec:**
- Display: inline-block
- Padding: 1px 6px
- Border-radius: 8px
- Font: 10px/500
- Background: `rgba(46, 204, 113, 0.15)`
- Color: `#2ecc71`
- Border: `1px solid rgba(46, 204, 113, 0.3)`
- Margin: 0 4px 2px 0

**Label transform:** Strip `supports_` and `outputs_` prefixes, replace underscores with spaces. Examples: `supports_imu` becomes "imu", `outputs_dense` becomes "dense", `supports_loop_closure` becomes "loop closure".

**Placement:** Below the dropdown trigger for the active backend (horizontal wrap). Inline within each dropdown list item.

**Only render for capabilities where value is `true`.**

### 4. ParameterPanel

**Location:** Below capability badges, within the AlgorithmSection.

**Behavior:** Renders dynamically from the active backend's `parameter_schema.properties`. One row per parameter.

**Parameter row layout:**
- Margin-bottom: 8px
- Label row: parameter key humanized (replace underscores with spaces, title case) in 11px/600/#aaa
- Description: parameter `description` value in 10px/400/#666, margin-bottom 4px
- Tunable indicator: Inline before label text
  - Live-tunable (`live_tunable: true`): lightning bolt character (U+26A1) in `#ff9800`, title="Changes apply live"
  - Startup-only (`live_tunable: false`): lock character (U+1F512) in `#888`, title="Requires restart"

**Numeric parameter control (type: "number" or "integer"):**
- Flex row: slider (flex: 1) + text input (width: 64px), gap: 8px
- Slider: native `<input type="range">`, min/max from schema, step = `(max - min) / 100` for float, `1` for integer
- Text input: `<input type="number">`, same min/max/step, background `#1a1a2e`, color `#e0e0e0`, border `1px solid #444`, border-radius 3px, padding 3px 5px, font-size 11px
- Both read from and write to same state value
- On text input change: clamp value to [minimum, maximum] before setting state
- On slider change: set state directly (already clamped by range input)

**Boolean parameter control (type: "boolean"):**
- Toggle button matching existing color mode toggle pattern
- Background: value ? `#1b5e20` : `#37474f`
- Color: `#e0e0e0`
- Border: `1px solid #444`
- Font: 11px/600
- Label: value ? "On" : "Off"
- Full width, padding 4px 8px

**Debounce for live-tunable parameters:** 200ms debounce on slider/input change before sending WebSocket message. Use simple setTimeout/clearTimeout pattern. Non-live-tunable parameters stage locally in `slamStore.stagedParams` without sending.

### 5. ConfirmModal

**Type:** Portal-based modal rendered to `document.body` via `ReactDOM.createPortal`.

**Backdrop:**
- Position: fixed, inset 0
- Background: `rgba(0, 0, 0, 0.6)`
- Z-index: 1000
- Display: flex, align-items: center, justify-content: center
- onClick: close modal (cancel action)

**Card:**
- Background: `#1a1a3e`
- Border: `1px solid #2a2a4a`
- Border-radius: 8px
- Padding: 24px
- Max-width: 400px
- Width: 90%
- Box-shadow: `0 8px 32px rgba(0, 0, 0, 0.5)`
- onClick: `e.stopPropagation()` (prevent backdrop close)

**Content:**
- Heading: "Switch Algorithm" in 16px/600/#e0e0e0
- Body: confirmation message in 13px/400/#aaa, margin-top 12px
- Button row: flex, gap 8px, margin-top 20px, justify-content: flex-end

**Buttons:**
- Cancel: background `#1565c0`, color `#fff`, padding 8px 16px, border none, border-radius 4px, font 13px/600, cursor pointer
- Switch: background `#2ecc71`, color `#fff`, same padding/border/radius/font/cursor

**Keyboard:** Escape triggers cancel.

### 6. RestartOverlay

**Location:** Rendered as a child of SceneViewer's container div, conditionally visible when `slamStore.isRestarting` is true.

**Visual spec:**
- Position: absolute, inset 0
- Background: `rgba(13, 13, 26, 0.7)` (semi-transparent deep background)
- Display: flex, flex-direction: column, align-items: center, justify-content: center
- Z-index: 10
- Pointer-events: none (user can still orbit the 3D view underneath if they want)

**Spinner:**
- 40px x 40px div
- Border: `3px solid #2a2a4a`
- Border-top-color: `#2ecc71`
- Border-radius: 50%
- Animation: `spin 1s linear infinite`
- Requires `@keyframes spin { to { transform: rotate(360deg); } }` added to `frontend/src/App.css`

**Text:**
- "Restarting with {algorithmDisplayName}..." in 14px/400/#aaa
- Margin-top: 12px

### 7. Error Banner (inline)

**Location:** Inside AlgorithmSection, below the dropdown, above parameter panel. Only visible when `slamStore.error` is non-null.

**Visual spec:**
- Background: `rgba(211, 47, 47, 0.15)`
- Border: `1px solid rgba(211, 47, 47, 0.3)`
- Border-radius: 4px
- Padding: 6px 8px
- Font: 11px/400
- Color: `#ef5350`
- Margin: 6px 0
- Display: flex, justify-content: space-between, align-items: center
- Dismiss button: "x" character, cursor pointer, no border, no background, color `#ef5350`, font-size 14px

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Switch" (in confirmation modal, confirming algorithm change) |
| Section header | "SLAM ALGORITHM" |
| Dropdown placeholder (before fetch) | "Loading backends..." |
| Dropdown empty state | "No backends available" |
| Empty parameter state | "No tunable parameters" (shown when parameter_schema.properties is empty) |
| Error state: fetch failure | "Failed to load SLAM backends. Check that the server is running." |
| Error state: switch failure | "Failed to switch to {name}. The previous algorithm is still active." |
| Error state: param update failure | "Parameter update rejected by backend." |
| Confirmation heading | "Switch Algorithm" |
| Confirmation body | "Switch to {displayName}? This will restart the current session." |
| Confirmation cancel | "Cancel" |
| Confirmation confirm | "Switch" |
| Restart overlay | "Restarting with {displayName}..." |
| Live-tunable tooltip | "Changes apply live" |
| Startup-only tooltip | "Requires restart" |
| Unavailable backend tooltip | "{reason}" (from backend, e.g., "orbslam3-python not installed") |

No destructive actions in this phase. Algorithm switching is disruptive (restarts session) but not destructive (no data loss -- point clouds are ephemeral). The modal confirmation is the safeguard.

## Interaction States

### AlgorithmDropdown

| State | Visual |
|-------|--------|
| Closed, backends loaded | Trigger shows active backend name, chevron down |
| Closed, fetching | Trigger shows "Loading backends..." in #888, no chevron |
| Open | Dropdown list visible below trigger, items listed |
| Item hover | Background `#222244` |
| Item active/selected | Left 2px green border, subtle green bg tint |
| Item unavailable | Opacity 0.4, cursor not-allowed, native tooltip on hover |
| Error | Error banner visible below dropdown |

### ParameterPanel

| State | Visual |
|-------|--------|
| Parameters loaded | Controls rendered per schema property |
| No parameters | "No tunable parameters" in 11px/#666 |
| Slider dragging (live) | Value updates in real-time, debounced WS send |
| Slider dragging (startup-only) | Value updates locally, staged in slamStore |
| Text input active | Standard browser focus ring on the input |

### ConfirmModal

| State | Visual |
|-------|--------|
| Visible | Backdrop fades in, card centered |
| Switch in progress | "Switch" button shows "Switching..." text, pointer-events: none, opacity 0.6 |

### RestartOverlay

| State | Visual |
|-------|--------|
| Restarting | Overlay visible with spinner + text |
| Complete | Overlay removed, new backend data loaded, point cloud cleared then rebuilds |
| Timeout (10s) | Error banner: "Restart timed out. Try again or refresh the page." |
