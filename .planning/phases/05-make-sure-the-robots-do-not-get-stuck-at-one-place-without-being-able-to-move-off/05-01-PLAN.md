    Create `src/locomotion/gait_controller.py` with class `TrotGaitController`:

    Diagonal pairs for trot gait:
    - PAIR_A = [0, 3] (FL index 0, RR index 3) -- in phase
    - PAIR_B = [1, 2] (FR index 1, RL index 2) -- anti-phase (offset by 0.5)
    - Leg order matches go2.xml actuator order: FL, FR, RL, RR
    - Each leg has 3 joints at indices [leg_idx*3, leg_idx*3+1, leg_idx*3+2] = [hip, thigh, calf]

    Constructor: __init__(self, params: GaitParams | None = None)
    - Store params (default GaitParams())
    - Initialize _phase = 0.0

    Method: compute(self, vx: float, vy: float, omega: float, dt: float) -> np.ndarray
    - Clamp speed = min(sqrt(vx^2 + vy^2), params.max_speed)
    - Advance _phase by params.frequency * dt only when speed > 0.01 or |omega| > 0.01
    - _phase wraps at 1.0
    - For each of 4 legs, compute leg_phase (PAIR_A uses _phase, PAIR_B uses (_phase + 0.5) % 1.0)
    - Call _leg_targets(leg_idx, leg_phase, vx, vy, omega, speed) to get (hip, thigh, calf)
    - Pack into 12-element array at [leg_idx*3 : leg_idx*3+3]

    Method: _leg_targets(self, leg_idx, phase, vx, vy, omega, speed) -> tuple[float, float, float]
    - v_scale = min(speed / max_speed, 1.0)
    - is_left = leg_idx in [0, 2] (FL, RL)
    - is_swing = phase < 0.5

    Hip target:
    - Start from standing_hip (0.0)
    - Add lateral: 0.1 * vy * (1.0 if is_left else -1.0)
    - Add turning: 0.05 * omega * (1.0 if is_left else -1.0)

    Swing phase (phase < 0.5):
    - swing_progress = phase / 0.5 (0 to 1)
    - lift = swing_height * 4.0 * swing_progress * (1.0 - swing_progress) (parabolic)
    - thigh = standing_thigh - lift * 2.0 (less flexion = higher foot)
    - calf = standing_calf + lift * 1.5 (tuck then extend)
    - Forward stride: stride_offset = stride_length * v_scale * (swing_progress - 0.5)
    - thigh += stride_offset * 0.5

    Stance phase (phase >= 0.5):
    - stance_progress = (phase - 0.5) / 0.5 (0 to 1)
    - thigh = standing_thigh
    - calf = standing_calf
    - Push backward: push_offset = stride_length * v_scale * (0.5 - stance_progress)
    - thigh += push_offset * 0.3
