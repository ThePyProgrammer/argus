# ORB-SLAM3 Vocabulary

The ORB feature vocabulary file (ORBvoc.txt, ~40MB) is required for
ORB-SLAM3 backend operation. It is .gitignored due to size.

## Download

Run from project root:

```bash
bash scripts/download_orbslam3_vocab.sh
```

## Source

From the official ORB-SLAM3 repository:
https://github.com/UZ-SLAMLab/ORB_SLAM3/tree/master/Vocabulary
